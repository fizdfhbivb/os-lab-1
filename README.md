## Описание

Решение на C демонстрирует:

- создание дочернего процесса через `fork()`;
- запуск отдельно скомпилированной программы через `execv()`;
- обмен через два канала `pipe()`;
- перенаправление файловых дескрипторов через `dup2()`;
- чтение и запись через `read()` и `write()`;
- работу с файлом через `open()` и `close()`;
- ожидание дочернего процесса через `waitpid()`;
- поиск пути к программе через `readlink()`.

По структуре взаимодействия решение аналогично [примеру преподавателя](https://gist.github.com/vladeemerr/dcf8ef920361e3f5a7aa6eaaeea77a4e).
Родитель и ребёнок находятся в отдельных файлах и собираются отдельно.
В коде нет комментариев; `stdio.h`, `threads.h` и `stdatomic.h` не используются.

## Условие варианта

Первой строкой пользователь вводит имя выходного файла, затем — по одному целому числу в строке.
Родитель передаёт имя файла ребёнку при запуске, а числа — через канал `pipe1`, связанный со стандартным входом ребёнка.
Дочерний процесс проверяет числа на простоту и записывает составные числа в файл.
При простом или отрицательном числе оба процесса завершаются.
Обратный канал `pipe2` передаёт подтверждения обработки и сигнал остановки.

Числа `0` и `1` пропускаются: они не являются ни простыми, ни составными.

## Сборка

Нужны Linux, компилятор C (GCC или Clang) и `make`.
В Windows используйте WSL; установленную Ubuntu можно открыть командой `wsl -d Ubuntu-24.04`.

Скачать репозиторий:

```sh
git clone https://github.com/fizdfhbivb/os-lab-1.git
cd os-lab-1
```

Минимальные команды для раздельной сборки двух программ:

```sh
mkdir -p build
cc -std=c11 -Wall -Wextra -Wpedantic -Werror -O2 src/parent.c -o build/parent
cc -std=c11 -Wall -Wextra -Wpedantic -Werror -O2 src/child.c -o build/child
```

Или с помощью Makefile:

```sh
make
```

## Запуск

Из корня проекта запустите родительскую программу:

```sh
./build/parent
```

Введите имя файла и числа, например:

```text
result.txt
4
6
9
7
```

На простом числе `7` работа завершится. Файл `result.txt` будет содержать:

```text
4
6
9
```

Посмотреть результат:

```sh
cat result.txt
```

**Важно:** исполняемые файлы должны называться `parent` и `child` и находиться в одной папке.
Родитель сам запускает `child` после `fork()`; отдельно запускать ребёнка не нужно.
Путь к нему определяется через `/proc/self/exe`.

Можно завершить ввод через `Ctrl+D` (EOF) или командой `exit`.
Имя файла вводится без обрамляющих кавычек; существующий файл перезаписывается.

## Особенности обработки

- Допустимы числа от `-2147483648` до `2147483647`, знак и окружающие ASCII-пробелы.
- В одной строке должно быть одно число. Пустая строка, неверный ввод, переполнение и строка длиннее 4095 байт завершают программу с кодом `1`.
- EOF завершает работу; последняя строка без перевода строки обрабатывается.
- Простые и отрицательные числа не записываются. Уже записанные числа сохраняются при последующей ошибке.
- Каталог выходного файла должен существовать. Относительный путь считается от текущей папки; пробелы и кириллица поддерживаются.
- По `pipe2` передаётся один байт: `R` — файл открыт, `C` — команда обработана, `S` — остановка, `E` — ошибка. После каждой команды родитель ждёт ответ.
- Неиспользуемые концы каналов закрываются, прерванные `read`, `write` и `waitpid` повторяются при `EINTR`, `SIGPIPE` игнорируется через `sigaction`.
- Проверка простоты перебирает делители до квадратного корня с условием `d <= n / d`.
- Код `0` означает штатное завершение. Ошибки выводятся в `stderr`; составные числа записываются только в файл.
